# 以损定仓计算器

按最大可承受亏损计算仓位，也支持加仓后的平均成本。

线上地址：https://sn0wjin19.github.io/loss-size-calc/

单页静态应用，打开即可用，不需要后端。

## 以损定仓

输入开单价、止损价、最大承受止损金额，以及单向手续费。

会算出：

- 仓位数量
- 仓位金额
- 预计手续费（开 + 平）
- 止损幅度
- 扣完手续费后的 1 : 1、1.5 : 1、2 : 1 止盈价

多空由开单价和止损价的高低自动判断。点「默认」会把当前手续费率记在本地，下次打开继续用。

## 加仓

标题右侧的「加仓」进入。输入持有仓位价格、仓位数量、加仓价格、加仓数量，会算出平均持仓成本和加仓后的持仓数量。

公式：

```
平均成本 = (持仓价 × 持仓量 + 加仓价 × 加仓量) / 总数量
持仓数量 = 持仓量 + 加仓量
```

也可以直接打开 https://sn0wjin19.github.io/loss-size-calc/#add
